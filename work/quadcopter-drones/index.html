Quadcopter drones

Designed, fabricated and flew two quadcopters on Arduino Uno and Mega flight controllers, running open-source firmware.

Role
Design, fabrication, tuning
Context
B.Tech Aeronautics major project
Built
Two airframes
Stack
Arduino Uno, Arduino Mega, open-source firmware
Context
Why two and not one? If the second was a response to what the first got wrong, say so — that is the whole story of this project.
Problem
What were you actually trying to achieve — flight time, payload, stability, autonomy? Name the target you were building against.
Constraints
Student budget, an 8-bit microcontroller, whatever components you could actually source. The Uno in particular is a real constraint worth naming — it is why the second build used a Mega, if that is what happened.
Architecture
Diagram goes here, and this one is genuinely worth drawing: sensors → flight controller → ESCs → motors, with the RC link and power system alongside. It is a control loop, and being able to draw a control loop is directly relevant to the systems roles you are targeting.
What I built
Frame, electronics, firmware configuration, PID tuning. Which parts were off-the-shelf and which did you design?
Outcome
Both flew — what did they do, and how well? Flight time, stability, anything you measured.
What I'd do differently
Crashes count here, and they read well rather than badly. What broke, what you diagnosed, what you changed. An engineer who can describe a failure precisely is more convincing than one who only reports successes.
