What I'm building, and what broke

A running record of the work behind this site and the AI engineering sprint alongside it. Updated as things ship. The failures are included on purpose — they carry more information than the wins.

1 Aug 2026

V1.3.1 — two mobile bugs I shipped

Both found on a real phone rather than in testing, which is the honest version of what happened.

Snag Fixing the email overflow in V1.3 introduced a worse-looking bug. I used overflow-wrap:anywhere, which stopped the page scrolling sideways but broke the address mid-word across two lines. The page measured correctly and read badly. Now the type is sized against the space actually available so the address always fits on one line.
Snag The fixed corner chrome — name, location, social links — sat transparently on top of scrolling content on mobile. It works on desktop because the content column is capped at 920px and centred, so the corners sit in the empty margin. On a phone the column is the full viewport and its text starts at exactly the same 28px offset the corners occupy, so they collided. Present since V1; the taller V1.2 hero made it obvious.

The top corner is now a real header bar — full width, opaque — so content passes beneath it. The bottom corners are hidden on mobile and their links moved into the menu; a second opaque bar would have cost another 44px of a small screen on top of the browser's own toolbar.

The lesson is about the test, not the CSS. I checked that no page scrolled sideways and treated that as "mobile is fine". Nothing checked whether fixed elements overlapped content, so a whole class of bug was invisible to the suite. That check now walks every text node against the chrome rectangles at each scroll position.

31 Jul 2026

V1.3 — case studies, this log, and a shared stylesheet

Added deep-dive pages for three projects, this log, Open Graph cards so the link stops previewing as a bare URL, and privacy-preserving analytics.

The structural change was pulling ~330 lines of inline CSS out into assets/site.css. V1 was deliberately a single file with no build step, and that was the right call for one page. At seven pages it stops being a constraint and becomes seven copies of the same stylesheet drifting apart.

Snag Splitting shared JS into its own file broke the case-study pages silently. The modules assumed homepage elements existed; the first getElementById returning null threw, and every module defined after it in the file stopped running — no console error loud enough to notice, just a dead cursor and a mobile menu that would not open. Fixed by making each module bail early when its own elements are absent.

Deliberately deferred: a retrieval-augmented chat over this site's content. The whole corpus is around 4,000 tokens against a 200,000-token context window, so retrieval would be decoration rather than architecture until there is more here to retrieve.

V1.1 — SEO, accessibility, and a cursor that would not let go

Added robots.txt, sitemap.xml, JSON-LD structured data, a themed 404 page, a skip link, and ARIA landmarks. Wrapped every section in module comments so the file stays navigable at 900 lines.

Snag The custom cursor stranded itself on mobile. Tapping added an active class and nothing ever removed it, so the dot sat frozen while content scrolled past underneath. Fixed with a scroll listener that clears it immediately plus a 600ms idle timeout for the case where someone taps and simply stops touching the screen.
